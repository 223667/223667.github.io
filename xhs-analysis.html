小红书 / 抖音双平台博主分析

2026.10 至今 ｜ 个人项目 ｜ TikHub API ｜ 54 篇作品样本 · 5 类画像数据

同一个人、同一批内容，为什么抖音能到 46 万赞，小红书只有 5 万？用同题材配对比较，把「平台差异」拆开来看。

要回答的问题

同内容跨平台分发，爆款量级由什么决定？哪些题材适合抖音引爆、哪些适合小红书沉淀？粉丝质量能不能支撑商业化判断？

我做了什么

  • 自己接入 TikHub API（账号、key、接口连通性验证），让 Agent 按接口取数。
  • 定义样本与口径：小红书 42 篇 + 抖音 12 篇 = 54 篇；按「同题材」配对，而不是只比总量。
  • 用点赞 / 收藏 / 分享三个比率区分内容类型：工具型看收藏率，观点型看分享率。
  • 核对数据与结论，产出剖析报告、双平台对照表和单文件交互看板。

方法

① 搜账号拿 user_id → ② 拉账号资料 / 作品 / 粉丝画像 / 相似博主 → ③ 同题材配对 → ④ 三率对比 → ⑤ 归纳平台调性并做看板。

结论

抖音是「引爆场」：天花板高，吃猎奇冷知识、搞钱副业；小红书是「沉淀场」：粉丝更粘，吃工具、审美和成长叙事。同一条内容两平台通吃的前提是「强观点」；工具型内容更适合放在小红书做收藏沉淀。

产出物与局限

产出：账号剖析报告、双平台爆款对照表、单文件交互式 HTML 看板（22KB，无后端依赖）、结构化数据摘录。

局限：分析对象是公开账号（momo / Www）而非本人账号；单样本、只覆盖抓取时点；不含商业转化数据，商业化判断只作参考。
